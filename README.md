# Shaik Rumaan | Resume website

A single-page, mobile-friendly personal resume site. Pure HTML and CSS, no build step.

## Use it
Open `index.html` in any browser, or host it on GitHub Pages.

## Reuse it as a template
1. Fork this repository.
2. Edit the text in `index.html` (name, experience, skills, contact).
3. Replace the embedded resume PDF if you want to keep the download button.
